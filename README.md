# Shivani Mehndi Artist

A professional business website created for Shivani Mehndi Artist and Mehndi training business.

## 🌐 Live Website

https://shivani-mehndi-artist.ai.studio/

## 📌 Project Overview

This project was created to build an online presence for a local Mehndi Artist and training business.

The website presents the business, Mehndi services, training courses, gallery, and contact information in a simple and organized way.

## ✨ Features

- Business information
- Mehndi services
- Mehndi training courses
- Gallery section
- Contact information
- Responsive website design
- Firebase integration
